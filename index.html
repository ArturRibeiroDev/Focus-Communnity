04 / EXPERIÊNCIA PROFISSIONAL

Aprenda a desenvolver como se trabalha em equipe.

A proposta não é só escrever código. É experimentar um fluxo de trabalho próximo ao de times reais: responsabilidades definidas, versionamento, revisão e entregas colaborativas.

GIT FLOW / NA PRÁTICA

De uma tarefa à entrega: um processo claro.

Nos projetos que utilizarem Git Flow, os participantes poderão praticar a criação de branches, o desenvolvimento isolado de funcionalidades, a abertura de pull requests e a integração das mudanças após revisão.

Git Flow é uma metodologia de trabalho com Git, não uma funcionalidade automática da plataforma. Cada squad poderá adaptar o fluxo à complexidade do projeto.

06 / PERGUNTAS FREQUENTES

O que você precisa saber antes de começar.

Respostas objetivas sobre participação, equipes, ideias e conclusão de projetos.

Preciso ter experiência profissional para participar?

Não. A comunidade tem como proposta o aprendizado prático. Escolha projetos compatíveis com seus conhecimentos e esteja disposto a colaborar, aprender e comunicar suas dificuldades.

Qual a diferença entre Focus Idea e projeto?

Uma Focus Idea é uma sugestão que pode inspirar a criação de algo novo. Um projeto é uma iniciativa concreta, criada por um participante, que pode reunir um squad e seguir pelas etapas de desenvolvimento.

Quando um projeto começa a ser desenvolvido?

Primeiro, o projeto fica em formação (FORMING). Quando a equipe estiver pronta, o responsável pode mudar seu status para ativo (ACTIVE), dando início à fase de desenvolvimento.

Como funciona o encerramento de um projeto?

O responsável pode marcar o projeto como concluído (COMPLETED). A plataforma registra evidências de participação para os integrantes, permitindo manter um histórico de colaboração.

Os projetos são apenas de programação?

Não. A comunidade contempla diferentes frentes de tecnologia, como front-end, back-end, mobile, QA, design, produto e dados. A composição de cada squad depende das necessidades do projeto.

Vou usar Git Flow em todos os projetos?

Git Flow é uma prática que os squads podem aplicar para aprender organização de branches, revisão e integração de entregas. O formato pode variar conforme as decisões da equipe e o tipo de projeto.

Já existe integração com GitHub ou emissão de certificados?

Ainda não. Integração com GitHub, gamificação e certificados são possibilidades futuras e dependem de definição, implementação e validação.

É obrigatório criar meu próprio projeto?

Não. Você pode se juntar a um projeto publicado por outra pessoa, desde que ele esteja aceitando participantes e haja uma vaga compatível.
